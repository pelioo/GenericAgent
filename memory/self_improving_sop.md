# Self-Improving SOP

> 自我改进机制，为GA记忆系统增添自我提升能力  
> 来源：self-improving skill | 整合者：GA | 优先级：HIGH  
> 最后更新：2026-05-03

---

## 🎯 定位

本SOP是GA记忆系统的**自我改进引擎**，负责：
1. 追踪用户纠正 → 转化为可执行规则
2. 积累任务反思 → 优化未来表现
3. 与L1-L4联动 → 形成学习闭环

---

## 📋 核心文件

| 文件 | 用途 |
|------|------|
| self_improving_sop.md | 本文件，核心流程 |
| self_improving_corrections.md | 纠正追踪日志 |
| self_improving_reflections.md | 自我反思日志 |

---

## 🔄 触发机制

### 1. 用户纠正触发（高优先级）
用户说："不用X，用Y" 或 "我说过要X" 或 "不要做Z"
→ 立即记录到 corrections.md，计数+1

### 2. 任务完成触发（自动）
每个复杂任务完成后（≥3轮对话）
→ 自动生成反思条目到 reflections.md

---

## 📊 纠正处理流程

[步骤1] 识别纠正类型
- 格式类 (代码风格/排版)
- 技术类 (方法/工具选择)
- 沟通类 (语气/表达方式)
- 项目类 (特定项目偏好)

[步骤2] 写入 corrections.md

[步骤3] 计数检查
- 计数 < 3 → 暂存，继续观察
- 计数 = 3 → 询问用户确认
- 计数 ≥ 3 + 确认 → 升级到记忆层

[步骤4] 升级到记忆层
- 通用规则 → L1 RULES
- 环境事实 → L2 global_mem.txt
- 任务模式 → 对应L3 SOP或新建

---

## ⚡ 执行规则

1. **立即响应**：用户纠正必须立即记录，不延迟
2. **不中断任务**：记录完成后继续当前任务
3. **3次确认**：必须达到阈值才升级
4. **显式同意**：隐式推断需要用户确认才能固化
5. **安全红线**：不存储密码/密钥/敏感信息

---

## 🚫 安全边界

| 禁止存储 | 处理方式 |
|---------|---------|
| 密码/API Key/Token | 不记录路径，只记录"已配置" |
| 财务/医疗/生物识别 | 严禁 |
| 未验证的推断 | 需用户明确同意 |
