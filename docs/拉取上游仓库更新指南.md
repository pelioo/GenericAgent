# 从主仓库拉取更新并手动审核合并指南

本文档将指导您如何使用最简单的方法从上游主仓库（https://github.com/lioensky/VCPToolBox）拉取更新，并手动审核更改内容。

## 1. 添加上游仓库

如果您尚未将主仓库添加为上游远程仓库，请执行以下操作：

```bash
# 添加上游仓库
git remote add upstream https://github.com/lioensky/VCPToolBox.git
```

## 2. 拉取并合并上游更新

使用以下两个命令即可完成拉取上游更新并合并到您的本地分支：

```bash
git fetch upstream
git merge upstream/main
```

## 3. 审核合并结果

合并完成后，您可以查看合并结果：

```bash
# 查看最近的提交记录
git log --oneline -5

# 查看当前状态
git status
```

## 4. 提交更改

确认合并结果符合预期后，推送到您的远程仓库：

```bash
git push origin main  # 或您的分支名
```

## 注意事项

- `git fetch upstream` 命令会获取上游仓库的最新更改，但不会立即合并到您的工作分支
- `git merge upstream/main` 命令将上游更改合并到当前分支
- 如果有冲突，Git 会在合并过程中提示您手动解决
- 合并后请务必测试项目功能是否正常
